# 令和4年度秋期・午前Ⅱの収録情報

- 対象：情報処理安全確保支援士試験 午前Ⅱ、全25問。アプリ上では科目A2相当として扱う。
- 公開一覧の確認日：2026年10月20日。
- 公開元：独立行政法人情報処理推進機構（IPA）。
- 問題・正答の正本：[IPA公式掲載ページ](https://www.ipa.go.jp/shiken/mondai-kaiotu/2022r04.html)。
- [公式問題PDF](https://www.ipa.go.jp/shiken/mondai-kaiotu/gmcbt80000008smf-att/2022r04a_sc_am2_qs.pdf)
- [公式解答例PDF](https://www.ipa.go.jp/shiken/mondai-kaiotu/gmcbt80000008smf-att/2022r04a_sc_am2_ans.pdf)

正答は公式解答例PDFから取得し、テストには公式PDFの問1〜25を独立して転記した。問題文・選択肢の入力補助には[ぱすてく](https://pasuteku.com/sets/2022r04a-sc-am2)の公開転載を用い、第三者の解説は取り込んでいない。公式PDFのページ画像で、抜き取りと図表・数式などの確認を行った（確認ページ：3（問1〜3の抜き取り）、10（問18）、11（問21）、12（問22）、13（問24））。解説は当サイト独自に作成し、既収録の再出題では選択肢の対応を確認して当サイトの解説を再利用した。

## 表示上の変更

- 英数字と日本語の間の空白、句読点、数式の表記を画面用に整形。
- 問16の公開鍵を用意する単位の組合せ表を、選択肢ごとの文章に整形。
- 問18のアドレス空間の累乗表記を復元。
- 問21のR表とS表は表名の列を持つ一つのHTML表に再構成。元の表にない列は「—」と明記し、NULLとは区別。SQL文を等幅表示し、結果表の選択肢は列順を明記した行の一覧に整形。
- 問22の流れ図をSVGで再作成。分岐網羅の設問として扱い、計算問題にはしない。
- 問24の投資案の表をHTML化し、同問を計算問題として扱う。5年分の運用費・削減額を使って各案を比較。

各問に復習単語を4〜8語設定し、それぞれの概念を用語集で学習できるようにした。解説の確認資料と用語の編集方針上の対応は[令和4〜6年度A2の補足](2022-2024-a2-notes.md)を参照。

問題IDは `sc-2022-autumn-a2-1` 〜 `sc-2022-autumn-a2-25`。
