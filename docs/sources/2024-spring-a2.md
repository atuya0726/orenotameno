- 問16の公開鍵を用意する単位の組合せ表を、選択肢ごとの文章に整形。
- 問21の人事表をHTML化し、SQL文を等幅表示。
- 問24の四つの課金グラフをSVGで再作成。選択肢の読み上げ用の説明文も付与。
- 計算問題はなし。課金グラフは知識問題として扱う。

各問に復習単語を4〜8語設定し、それぞれの概念を用語集で学習できるようにした。解説の確認資料と用語の編集方針上の対応は[令和4〜6年度A2の補足](2022-2024-a2-notes.md)を参照。
