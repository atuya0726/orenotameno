# 令和4年度春期・午前Ⅱの収録情報

- 対象：情報処理安全確保支援士試験 午前Ⅱ、全25問。アプリ上では科目A2相当として扱う。
- 公開一覧の確認日：2026年10月20日。
- 公開元：独立行政法人情報処理推進機構（IPA）。
- 問題・正答の正本：[IPA公式掲載ページ](https://www.ipa.go.jp/shiken/mondai-kaiotu/2022r04.html)。
- [公式問題PDF](https://www.ipa.go.jp/shiken/mondai-kaiotu/gmcbt80000009sgk-att/2022r04h_sc_am2_qs.pdf)
- [公式解答例PDF](https://www.ipa.go.jp/shiken/mondai-kaiotu/gmcbt80000009sgk-att/2022r04h_sc_am2_ans.pdf)

正答は公式解答例PDFから取得し、テストには公式PDFの問1〜25を独立して転記した。問題文・選択肢の入力補助には[ぱすてく](https://pasuteku.com/sets/2022r04h-sc-am2)の公開転載を用い、第三者の解説は取り込んでいない。公式PDFのページ画像で、抜き取りと図表・数式などの確認を行った（確認ページ：3（問1・2）、4（問4）、8（問12）、12（問22）、13（問24））。解説は当サイト独自に作成し、既収録の再出題では選択肢の対応を確認して当サイトの解説を再利用した。

## 表示上の変更

- 英数字と日本語の間の空白、句読点、数式の表記を画面用に整形。
- 問1のHTTPリクエストヘッダを改行付きの等幅表示に再構成。
- 問4の四つの数式を復元し、同問を計算問題として扱う。
- 問12のクラウドの責務分担の表をHTML化。
- 問24の停止状況の表をHTML化し、同問を計算問題として扱う。顧客との合意がある計画停止を提供時間から除いて計算。
- ガイドラインや監査基準の設問は、問題文に指定された版を前提として解説。

各問に復習単語を4〜8語設定し、それぞれの概念を用語集で学習できるようにした。解説の確認資料と用語の編集方針上の対応は[令和4〜6年度A2の補足](2022-2024-a2-notes.md)を参照。

問題IDは `sc-2022-spring-a2-1` 〜 `sc-2022-spring-a2-25`。
