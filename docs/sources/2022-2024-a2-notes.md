# 令和4〜6年度A2の解説・用語の補足

令和4〜6年度の情報処理安全確保支援士試験の午前Ⅱを、春期・秋期各25問、計150問追加した。既収録の令和7年度50問と合わせて、科目A2は8回分・全200問になる。問題文・選択肢・正答の正本は、各回の収録情報に記載したIPA公式PDFである。

## 解説と用語

全問に選択肢別の解説と判断の手掛かりを設け、復習単語を4〜8語ずつ設定した。解説は当サイト独自に作成し、既収録の再出題では選択肢の内容と順番を確認して当サイトの解説を再利用した。第三者の解説・図は転載していない。

復習単語に対応する新規用語247語と、同じ概念の表記ゆれの別名を追加した。各用語は1概念を対象とし、Bの要点を中心に必要な評価観点だけを設けた。AやSの観点を埋めるための項目は追加していない。

既存の別名のうち、今回の復習単語で異なる概念を開いていたものは独立させた。例えば、RAとPKI、サプリカント・オーセンティケータ・RADIUS・EAPとIEEE 802.1X、OCSPとCRL、公開鍵・秘密鍵と公開鍵暗号方式、プレースホルダとSQLインジェクション、無線LANとPoE、全般統制と業務処理統制などを分けた。ハッシュ値とハッシュ関数、外部キーと参照制約などもそれぞれの概念へ対応させ、分離した関連語の定義を元の用語の必須観点から外した。既存の用語IDと保存済みの学習記録は維持する。

規格・制度・法令は問題文で指定された版や前提に沿って解説した。特にCSF 1.1は五つの機能、CSF 2.0はGOVERNを含む六つの機能であることを区別した。著作権の設問は、許諾や法令上の条件があることを前提に説明した。
